## Project Overview

This project showcases data analysis and visualization using **Microsoft Power BI** across three datasets: AmazingCart, Customer Data, Employee Layoffs and FlightData.

### Key Tasks Performed
- Created DAX measures to calculate the sum of numerical columns, total rows, valid records, missing values, minimum values, and maximum values.
- Prepared summary statistic cards to highlight key metrics for selected columns.
- Created a **Clustered Column Chart** using the AmazingCart dataset to compare values across categories.
- Created a **Line Chart** using the Customer Data dataset to analyze trends over time.
- Created a **Pie Chart** using the Employee Layoffs dataset to visualize the distribution of layoffs by location.
- Practiced data cleaning, data summarization, and visual formatting to present insights effectively.

### Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization

### Key Takeaways
Applied data modelling, DAX calculations, and visualization techniques to transform raw datasets into clear, structured, and meaningful visual reports.
